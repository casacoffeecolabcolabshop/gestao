# 05 Fluxos

## Avisar que algo acabou (funcionário, ~5s)
Compras → botão **+ Acabou algo** → digita nome → (quantidade, tipo, urgente) → **Adicionar** → toast "Adicionado".

## Colar uma lista inteira (qualquer pessoa, ~15s)
Compras → **+ Acabou algo** → **Vários de uma vez** → escreve ou cola um item por linha → **Adicionar** → toast "5 adicionados · 1 já estava na lista".

## Ver o que falta comprar e levar no celular ou impresso (qualquer pessoa)
Compras → botão **Para comprar** no topo → painel com Urgentes, Insumos e Produtos → **Baixar PDF** (opcional).

## Fazer as compras (gerente)
Compras → lista de pendentes → toca no item → fica verde "Comprado" (com desfazer por 5s).
Ou, no mercado: Compras → **Para comprar** → toca no check de cada item conforme pega → fica verde e riscado, topo mostra "3 de 9 comprados". O que não comprou continua pendente para a próxima vez.

## Montar a escala (gerente)
Escala → semana atual → toca no dia → **+ Turno** → pessoa, início, fim → **Salvar**. Botão **Copiar semana anterior** para não começar do zero.

## Mandar meus horários (funcionário)
Escala → no dia → **+ Meu turno** → começo e fim → **Mandar** → aparece amarelo "Aguardando" até o gerente aprovar.

## Aprovar horários da equipe (gerente)
Escala → bloco **Turnos para aprovar** no topo → **Aprovar** ou **Recusar** (desfazer por 5s).

## Ver minha escala (funcionário)
Escala → semana com meus turnos destacados + "Suas horas: 32h".

## Pedir troca ou folga (funcionário)
Pedidos → **+ Novo pedido** → Folga (dia) ou Troca (meu turno + quem cobre) → **Enviar** → aparece amarelo "Aguardando".

## Aprovar pedido (gerente)
Pedidos → aba Pendentes → **Aprovar** ou **Recusar** → aviso com **Desfazer** por 5s → escala atualiza sozinha.

## Conversar com a equipe
Compras ou Escala → botão **Chat** no topo (com número de novas) → escreve → **Enviar**. Mensagens dos outros aparecem sozinhas.

## Entrar no app
Primeira vez ou sempre: **Entrar com Google** → escolhe a conta → já cai em Compras como funcionário.
Sem Google: **Criar conta** → nome, e-mail, senha (2x) → **Criar conta** → entra (ou "Confira seu e-mail" e entra pelo link). Próximas vezes: e-mail + senha.
Ou, por convite: dono convida pelo painel do Supabase → pessoa recebe e-mail → cria senha → entra. Próximas vezes: e-mail + senha.
